Momentum leaderboard

A weekly momentum score for 4 named tools this site tracks — Claude Code, Codex, Cursor, and GitHub Copilot. Each one's score blends 40% GitHub repo-count growth, 30% Hacker News comment growth, and 30% Google Trends search interest into a single number, recalculated every Monday.

This ranks GitHub repo-count alone, not the full momentum Score in the table below - momentum.json only keeps this week's snapshot, so repo-count history is the closest available stand-in for past weeks' rank. The two can disagree: a tool can lead here (most repos) while trailing on Score (the 3-signal blend), or vice versa.

#ToolScore7-day

Score = 40% GitHub repo-count growth (topic-tagged repos, via the GitHub API) + 30% Hacker News comment-count growth (via the Algolia HN Search API) + 30% Google Trends search interest, 0–100 (via a third-party Trends proxy - see the README for the reliability caveat on that one). Growth compares each week's snapshot against whichever earlier snapshot is closest to 7 days prior, not just the previous row, so an off-schedule manual run doesn't get compared against a too-recent point. Growth terms are then clipped to ±50% before blending, so one noisy week can't dominate the score. A tool without Google Trends coverage (currently Cursor - "Cursor" is too generic a search term to track cleanly) uses the average of the other tools' actual Trends values that week for that third, instead of an arbitrary fixed number. This is a first-pass formula — worth revisiting once there's more than a few weeks of history to check it against.

Momentum recalculated every Monday alongside the trends data refresh.
