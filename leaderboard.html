Every number here is a raw, unblended measurement - no formula, no weighting, no ranking. GitHub repos = count of repos tagged with that tool's topic, via the GitHub API. HN comments = Hacker News comment volume this week, via the Algolia HN Search API. Reddit mentions = post count for that tool's search term over the past week, via Reddit's official OAuth search API - the count is capped at 100 results per request rather than a true total, so a very active week can look identical to a merely busy one. Trends interest = Google's 0–100 relative search-interest index, via a third-party proxy - see the README for the reliability caveat and a confirmed case of it silently missing a week's data point. VS Code installs = the extension's total install count from the VS Code Marketplace's own public API - the one number on this page that's a direct usage count rather than a proxy for one. 7-day columns compare each week's snapshot against whichever earlier snapshot is closest to 7 days prior, not just the previous row, so an off-schedule manual run doesn't get compared against a too-recent point. A dash means that signal genuinely isn't tracked for that tool (Cursor has no Trends coverage - "Cursor" is too generic a search term to track cleanly; Replit Agent, Devin, and Lovable have no GitHub signal - none of them are tools people build a public GitHub ecosystem of extensions/example repos around; only tools that ship an actual VS Code extension have install counts at all - Cursor and Windsurf are standalone forked editors, and Replit Agent, Devin, and Lovable are browser-only; Hacker News and Reddit are the two signals every tool here has) - never a fabricated zero.
